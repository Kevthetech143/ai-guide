Last full review: 2026-09-26

Badges, in plain words: Open source — anyone can download and inspect how it works. Company-made — a company runs it for you. Free — you can use the main features without paying. Paid — you need to pay, usually a monthly plan. Runs on your computer — it runs on your own device, nothing sent to the cloud. Easy / Medium / Hard — how tricky it is to set up and use.

Claude Code

Paid Medium Company-made Runs on your computer

An AI coding helper that works in your terminal; it can read your whole project, make changes, and run tests.

Price: $17/month (billed annually; $20 monthly)
Difficulty: Medium

There is no free access, and usage limits mean heavy coding days can hit the cap.

Paid Medium Company-made

Agentic AI code review on pull requests — rules system, pre-PR checks, analytics

Difficulty: Medium
