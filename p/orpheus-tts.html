Provider

Orpheus TTS

Made by Canopy Labs

Free Hard Open source Runs on your computer

Free, expressive text-to-speech you can run yourself, with emotion tags (like laughing or sighing) and voice cloning from a short sample.

  • PriceFree
  • DifficultyHard
  • Good forVoice

There is no app to click: you install it with Python commands and run it as code. The main models are English; other languages are only a research preview.
