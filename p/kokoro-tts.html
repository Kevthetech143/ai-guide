Kokoro

Made by hexgrad

Free Hard Open source Runs on your computer

A small, fast open text-to-speech model that reads text aloud in a natural voice. Light enough to run on an ordinary computer.

  • PriceFree to run yourself
  • DifficultyHard
  • Good forVoice

It is a model, not an app, so you need some Python skills or a tool built on top of it. Check the model page for which languages and voices it covers.
