# SEO structured data + sitemap cleanup (ai-guide-012, 2026-09-16)

Code changes: `build.py` and `templates/base.html` only.
Backups taken before editing: `build.py.bak-20260916-seo`,
`templates/base.html.bak-20260916-seo`.
JSON-LD is emitted with `json.dumps` (never string concatenation), so a
quote or unicode character in a blurb cannot break a page. Every
question/provider page carries exactly one `<script type="application/ld+json">`
block; home has one; all other pages (category, start-here, about, all) have none.

## Schema by page type

### Question pages — `dist/best/<slug>/` (36 pages)
One block using `@graph` with two schema types:
- **FAQPage**: `mainEntity` is a single `Question` (`name` = the page's
  question title) with `acceptedAnswer` = an `Answer` whose `text` is the
  page's intro text (`q["intro"]` from `data/questions.json`).
- **ItemList**: `name` = question title; `itemListElement` is a `ListItem`
  per matched provider card **in display order**, each with `position`
  (1-based), `name`, and `url` (the provider page's canonical URL).

### Provider pages — `dist/p/<id>.html` (60 pages)
- **SoftwareApplication** with: `name` (provider name), `applicationCategory`
  (the provider's first category, plain label e.g. "Chat"), `description`
  (the provider's `good_for` text verbatim).
- `offers`: included only when `price_from` contains a real dollar amount
  (regex `\$(\d+(\.\d{1,2})?)` on the raw value). Emitted as
  `{"@type":"Offer","price":"8","priceCurrency":"USD"}`. Omitted entirely for
  the 11 `"Free"` providers and for `"Check site"` /
  `"Free (open weights); usage-based API pricing"` (no dollar figure).
  Result: 47 pages with offers, 13 without.

### Home page — `dist/index.html`
- **WebSite** with `name: "AI Guide"` and `url` = the site base URL.

## Deliberately left out (and why)
- **aggregateRating / reviewCount / author on SoftwareApplication**: we have
  no ratings, reviews, or editorial authorship data. Inventing them is fake
  schema and risks a search-engine penalty.
- **`operatingSystem`, `softwareVersion`, `url`/`screenshot` on
  SoftwareApplication**: brief fixed the field list to name, category,
  description, offers. The provider's official link is already on the page
  as a card link.
- **Structured data on category/start/about/all pages**: brief scoped schema
  to question pages, provider pages, and home. Their existing canonical tags
  were untouched.
- **`og:type` change**: left as-is per the "do not redo existing tags" rule.

## Sitemap cleanup
- Old sitemap had 136 entries including both `https://kevthetech143.github.io/ai-guide/`
  and the duplicate `.../ai-guide/index.html`. The `/index.html` twin is dropped;
  the home is listed once under its canonical form.
- The start-here picker's canonical tag was `.../start/index.html`; the
  filtered start pages used `.../start/<rel>/index.html`. Both now use the
  trailing-slash page URL (e.g. `.../start/`, `.../start/free/`), so the
  sitemap uses the same canonical form as the `<link rel="canonical">` tag
  on every page.
- Every entry now carries `<lastmod>2026-09-16</lastmod>`.
- Result: **135 entries, zero duplicate `<loc>`, zero `/index.html` entries**
  (asserted at build time — the build refuses to emit dupes or twins).
