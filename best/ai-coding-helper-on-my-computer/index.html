Which AI coding helper can I install on my computer?

231 of 231 listings checked in the last 30 days. Oldest check: October 9, 2026.

Cursor and GitHub Copilot help you write, fix, and explain code inside a code editor, the program where code is written. Aider and Claude Code work in your computer's terminal, a text window where you type commands. Dyad is a free desktop app that turns a plain-English description into a working web app.

Badges, in plain words: Open source — anyone can download and inspect how it works. Company-made — a company runs it for you. Free — you can use the main features without paying. Paid — you need to pay, usually a monthly plan. Runs on your computer — it runs on your own device, nothing sent to the cloud. Easy / Medium / Hard — how tricky it is to set up and use.

Cursor

Free Easy Company-made Runs on your computer

It is an app where an AI assistant helps you write, fix, and explain code right in your editor.

Price: Free tier available; paid plans from $8/month
Difficulty: Easy

The free plan has limited AI use; the $8 Plus plan only works with Grok models, and other companies' models are billed extra on the Premium plan ($30 a month).
